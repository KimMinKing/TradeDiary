# 공개 프로필 세부 공개 범위

## 변경 사항

기존에는 `diary_public` 하나로 일기, 통계, 포지션, 체결 내역과 총 자산까지 함께 공개됐다. V105부터 다음 설정을 독립적으로 관리한다.

- `profile_public`: 공개 프로필 진입 자체
- `diary_public`: 공개로 지정된 일기
- `stats_public`: 승률, 손익, 연승·연패 통계
- `positions_public`: 포지션 내역
- `trades_public`: 개별 체결 내역
- `assets_public`: 총 자산

프로필이 비공개이면 모든 하위 공개 API가 차단된다. 설정 UI에서 하위 항목을 켜면 프로필 공개가 함께 켜지고, 프로필을 끄면 모든 하위 설정이 꺼진다.

## 기존 데이터 이관

기존 `diary_public=true` 사용자의 프로필·통계·포지션·체결 공개 상태는 보존한다. 총 자산은 민감 정보이므로 모든 사용자에게 `false`로 시작한다.

로컬 적용 결과 기존 공개 사용자 23명의 공개 상태가 보존됐으며, 총 자산 공개 사용자는 0명이다.

- 프런트엔드 프로덕션 빌드 통과
