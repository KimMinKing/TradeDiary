# TradeNote 발표 대본 (6분)

---

## 1. 한 줄 소개 (30초)

"안녕하세요. 저는 **TradeNote**라는 서비스를 만들었습니다.
코인 트레이더가 자신의 거래 기록을 분석해서 더 나은 투자자가 되도록 돕는 플랫폼입니다."

---

## 2. 왜 만들었는가 — 문제 (40초)

"많은 코인 트레이더들이 이런 경험을 합니다:
- 거래는 많이 하는데 왜 수익이 안 나는지 모르겠다
- 감정적으로 매매해서 후회하는 패턴이 반복된다
- 거래소 화면에만 의존해서 자신의 매매 습관을 객관적으로 볼 기회가 없다

TradeNote는 이 문제를 해결합니다.
거래소 API를 연결하면 자동으로 거래 데이터를 가져와서
포지션 단위로 묶고, 통계를 내고, AI가 분석해 줍니다."

---

## 3. 어떤 사람이 쓰는가 (30초)

"주요 사용자는:
- 하루에도 여러 번 코인을 사고파는 **스캘핑/단기 트레이더**
- 자신의 매매 패턴을 객관적으로 분석하고 싶은 사람
- 거래 일기를 쓰면서 감정과 성과의 관계를 알고 싶은 사람

Upbit, Bybit, Binance, Bitget, OKX, BingX — 국내외 6개 거래소를 지원합니다."

---

## 4. 핵심 기능 — 데모 순서 (3분)

### 4-1. 대시보드 (30초)
> 화면: 대시보드 페이지

"접속하면 이번 달 성과가 한눈에 보입니다.
손익, 승률, 전달 대비 변화, 그리고 오늘 해야 할 매매 계획까지 보여줍니다."

### 4-2. 거래소 연동 + 포지션 자동 분석 (40초)
> 화면: 거래소 등록 → 포지션 목록

"거래소 API Key를 등록하면 5분마다 자동으로 거래 내역을 가져옵니다.
가져온 거래를 **순수량이 0이 되는 기준**으로 하나의 포지션으로 자동 묶습니다.
예를 들어 BTC를 3번 사고 3번 팔아서 잔량이 0이 되면 하나의 포지션으로 종료 처리됩니다."

### 4-3. 매매 일기 + 감정 기록 (40초)
> 화면: 일기 작성 페이지

"각 포지션에 대해 일기를 쓸 수 있습니다.
진입 이유, 청산 이유, **그때의 감정 상태**(불안, FOMO, 확신 등)를 기록합니다.
전략 태그도 붙일 수 있고, 사진 첨부도 됩니다.
나중에 'FOMO일 때 수익이 어떻게 됐지?' 하고 분석할 수 있습니다."

### 4-4. 매매 계획 vs 실적 비교 (30초)
> 화면: 대시보드의 '다음 매매 할 일' + '계획 vs 실적'

"매매 전에 계획을 세울 수 있습니다.
'BTC LONG 하겠다'라고 적어두면, 실제로 그날 BTC를 LONG으로 샀는지
아니면 전혀 다른 종목을 샀는지 자동으로 비교해 줍니다.
계획을 지키는 습관을 만들어줍니다."

### 4-5. AI 분석 리포트 (30초)
> 화면: 통계 페이지 → AI 리포트

"GPT-4o mini가 거래 데이터를 분석해서 리포트를 만들어줍니다.
시간대별 승률, 연속 손실 패턴, 종목별 성과 등을 자연어로 정리해 줍니다."

### 4-6. 랭킹 + 커뮤니티 (10초)
> 화면: 랭킹 페이지

"다른 트레이더들의 공개 일기를 볼 수 있고,
이번 달 승률 랭킹도 확인할 수 있습니다."

---

## 5. 기술 스택 간단 소개 (30초)

"백엔드는 Java Spring Boot, 프론트엔드는 React,
AI 분석은 Python FastAPI, 데이터베이스는 PostgreSQL입니다.
전체가 Docker로 배포되고, 클라우드 서버에서 돌아갑니다."

---

## 6. 마무리 (20초)

"TradeNote는 단순한 거래 기록 도구가 아니라,
트레이더가 자신을 객관적으로 돌아보고 성장할 수 있도록 돕는 **거래 일기 분석 플랫폼**입니다.

감정 기록, 계획 vs 실적 비교, AI 분석으로
무작정 거래하는 단계에서 **계획적이고 데이터 기반의 트레이딩**으로 성장할 수 있습니다.

감사합니다."

# 데모 동영상 촬영 가이드

## 촬영 순서 (총 2~3분 분량)

### 장면 1: 로그인 + 대시보드 (20초)
- 로그인 화면 → 대시보드 진입
- 이번 달 성과, 오늘의 매매 계획, 계획 vs 실적 카드 순서로 보여주기
- 하단 퀵 링크 스크롤

### 장면 2: 거래소 연동 + 포지션 (30초)
- 설정 → 거래소 API Key 등록 화면
- 포지션 목록 페이지: 필터(거래소 탭, 날짜) 사용
- 개별 포지션 클릭 → 상세 정보

### 장면 3: 매매 일기 작성 (30초)
- 캘린더에서 날짜 선택
- "일기 작성" 버튼 클릭
- 진입/청산 이유 입력
- 감정 선택 (FOMO, 불안 등)
- 전략 태그 선택
- 거래 참조 선택 (좌측 거래 카드 클릭)
- 저장 → 작성된 일기 확인

### 장면 4: 매매 계획 (20초)
- 매매 계획 탭 이동
- 새 계획 작성: "BTC LONG", 날짜, 내용
- 저장 → 계획 목록 확인
- 완료 체크 토글

### 장면 5: 통계 + AI 리포트 (20초)
- 통계 페이지 이동
- 승률 차트, 종목별 성과 확인
- AI 리포트 생성 버튼 클릭 → 결과 확인

### 장면 6: 랭킹 + 공개 프로필 (15초)
- 랭킹 페이지
- 다른 사용자 프로필 클릭 → 공개 일기 확인

### 장면 7: 모바일 반응형 (15초)
- 브라우저 창 축소 또는 개발자 도구 모바일 모드
- 하단 탭바 동작 확인
- 카드 레이아웃 반응형 확인

---

## 촬영 팁
- 브라우저 확장으로 화면 녹화 (OBS, Chrome 확장 Loom 등)
- 모바일은 Chrome 개발자 도구 → 디바이스 툴바 사용
- 더미 데이터가 있어야 시연이 자연스러움 (seed_dummy_data.sql 활용)
